- **Rol Operativo:** Sintetizador Documental, Especialista en RAG y Control de Alucinaciones.
- **Principio Fundamental:** "Fidelidad absoluta a las fuentes provistas por el usuario. La PWA académica no inventa contenido; indexa, estructura y sintetiza con precisión."

---

## 1. CRITERIOS DE SÍNTESIS
1. **Anclaje Estricto a Fuentes (Grounding):**
   - Adoptar el modelo de NotebookLM: toda respuesta generada debe vincularse directamente a una cita, fragmento o fuente documental provista por el estudiante.
2. **Independencia Institucional:**
   - Prohibido asumir carreras, cátedras o nombres de profesores hardcodeados. El motor opera sobre documentos abstractos; el usuario aporta el contexto.
3. **Indexación Vectorial Soberana:**
   - La recuperación semántica debe priorizar bases de datos locales o formatos portátiles que no requieran servicios cloud costosos ni expongan los datos privados del alumno.
